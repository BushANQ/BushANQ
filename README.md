## About Me

I'm an **information security student and independent researcher**. I focus on malware analysis, threat intelligence, and agentic security systems—turning fragmented security information into actionable research and tools.

一名专注于信息安全的学生与研究者。主要关注恶意软件分析、威胁情报、逆向工程与 Agent Harness，探索 AI Agent 在安全研究和复杂任务自主协作中的实际应用。

- **Research** &nbsp; Threat Intelligence · Malware Analysis · Reverse Engineering · Agent Harness
- **Security** &nbsp; Penetration Testing · Threat Hunting · Security Automation
- **Exploring** &nbsp; NGAV / EDR · Kernel Development · Active Directory Security · Agentic Workflows
